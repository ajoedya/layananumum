# Data bahasa OCR

`ind.traineddata.gz` dan `eng.traineddata.gz` berasal dari paket npm `@tesseract.js-data/{ind,eng}` versi `4.0.0_best_int`
(turunan tessdata Tesseract OCR), berlisensi Apache License 2.0. Mesin OCR di `../core` berasal dari `tesseract.js-core@7.0.0`
(lihat `../core/LICENSE`). Semuanya disimpan di sini supaya OCR tidak mengunduh apa pun dari CDN.
