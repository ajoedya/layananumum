# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Stripe
- **Notes:** Situs Layanan Subbagian Umum KPKNL Balikpapan (beranda, Olah PDF, Dashboard Anggaran/jagakas, Monitoring E-Perjadin). Pertahankan identitas yang sudah ada, yaitu navy dan emas, huruf Public Sans, kop foto Balikpapan, serta mode terang/gelap lewat `tema.js`. Tabel angka memakai angka tabular, rata kanan, dan hierarki yang jelas.

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary
- Floating pastel pill badges for ordinary metadata
- Arbitrary decorative gradients and neon glowing borders
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and icon bloat inside inputs

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** 4.5:1 untuk teks biasa, 3:1 untuk teks besar dan batas elemen, di mode terang maupun gelap
- **Touch / focus:** Target sentuh minimal 44×44px, cincin fokus terlihat pada semua kontrol

## Brand tone and microcopy voice

- **Voice:** Utilitarian & Minimal
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Bahasa Indonesia baku sesuai EYD Edisi V, tanpa tanda pisah panjang (em dash). Istilah anggaran mengikuti istilah resmi (pagu, realisasi, blokir, RO, akun) dan dipakai konsisten di semua halaman.

## Icon library

- **Library:** Project SVG
- **Package / path:** SVG inline di dalam berkas HTML tiap halaman
- **Notes:** Satu gaya garis yang sama untuk semua ikon; jangan campur pustaka ikon dan jangan pakai emoji sebagai ikon antarmuka.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
